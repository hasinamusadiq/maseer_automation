# ?? Maseer Automation

AI-powered video marketing automation for Afghan businesses.

## ?? Setup

1. Add secrets in Settings → Secrets → Actions:
   - `GROQ_API_KEY`
   - `HF_TOKEN`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

2. Run workflow manually or wait for scheduled run

## ?? Structure
- `src/` - Python modules
- `data/clients.json` - Client database
- `.github/workflows/` - CI/CD pipelines
